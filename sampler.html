Sampler Parameters
SLICEEqual slices from C-1 01 FILE uses markers saved in the wav
PLAYFWD, REV, FWDLOOP, REVLOOP FWD PP and REV PP ping-pong back and forth
OSCOscillator modes Ignore START and don't restart on retrigger
REPITCHREPITCH/BPM Pitch follows tempo; set STEPS/BPM below
STARTStart point STA command; ignored in OSC modes
LOOP ST.Loop start Where looping modes jump back to (LOP)
LENLength How much of the sample plays
DETUNEDetune 80 = center; 1st digit semitones, 2nd 1/16 semitone
DEGRADESample-rate crunch Above 00 also turns off interpolation
SLISlice command Cue a slice marker from a phrase or table
Good to Know
Slices Use the Note ColumnPIT
  • With SLICE on, the note picks the slice, not the pitch
  • PIT per step repitches one slice; DETUNE shifts them all
Each Track Is a Choke GroupONE TRACK
  • A new hit cuts off the last one on the same track
  • Put open and closed hats on one track so the open hat chokes
Keep the CPU HappyMONO · 16-BIT
  • Mono for kicks and bass; 16- or 8-bit instead of 24/32-bit
  • Avoid pitching a sample an octave or more above its original
Lo-Fi TextureDEGRADE
  • DEGRADE here, or DOWNSAMPLE / 8-BIT in the editor
  • A RANDOM LFO on DEGRADE crunches each hit differently
Linear DrummingONE TRACK
  • Kick, snare, and hats on one track, so no hits overlap
  • Change the instrument per step; each hit gets its own space

Editing & Recording
Crop a Loop to the BeatOPT + UP/DOWN
  • In SELECT, OPT + UP/DOWN snaps markers to the song's beats
  • Select exactly 1, 2 or 4 bars, then PROCESS → CROP
Lazy ChopPLAY + EDIT
  • Highlight SLICE MARKER and play the sample
  • Tap PLAY + EDIT on each hit to drop a marker there
  • SAVE, then set the instrument's SLICE to 01 FILE
Record Your OwnREC.
  • EDIT on REC.; SRC picks line-in, USB, or TR1–8
  • ARM starts recording once the input passes a threshold
  • Process, name, and SAVE before leaving the editor
Build a Kit SampleQUICK RENDER
  • Sequence your one-shots in a phrase, one per step
  • Quick render the selection, then PROCESS → SLICE:AUTO
  • One instrument now plays the whole kit from C-1
Random SlicesRNL
  • RNL in the first FX column randomizes the note (the slice)
  • Keep its second digit 0 so the instrument doesn't change
  • SED at the phrase start repeats a take you like
Recipes
Chop a BreakSLICE:AUTO
  • Editor: PROCESS → SLICE:AUTO (or SLICE:16), then SAVE
  • Instrument: SLICE → 01 FILE; notes from C-1 play the slices
  • Rearrange notes, RET 03 on snares, CHA on ghost hits
Loops in TempoREPITCH/BPM
  • PLAY → REPITCH/BPM; set STEPS/BPM to the loop's length
  • Changing TPO keeps it in time (the pitch moves with it)
Resample & LayerEDIT ×2
  • Song view: SHIFT + OPTION select phrases, double-tap EDIT
  • QUICK RENDER creates a new instrument (needs a free slot)
  • Slice, DEGRADE, or re-render it: layers without using tracks
Pad From a One-ShotFWDLOOP
  • PLAY → FWDLOOP; set LOOP ST. inside the steady part
  • XFADE LOOP in the editor removes the loop click
  • ADSR on volume with a long REL; end notes with OFF
Humanized One-ShotsLFO RANDOM
  • MOD → LFO, OSC RANDOM, TRIG RETRIG
  • Low AMT on CUTOFF or volume: every hit sounds a bit different
Old-School WarpSTA
  • Short notes with a new STA each step replay from new spots
  • Play low notes for slowed, grainy textures
Reverse SwellPLAY REV
  • PLAY → REV on a crash or vocal, timed to end on the downbeat
  • Reverse reverb: quick render it with REV, then REVERSE
Timestretch LoopLFO → LOOP ST.
  • PLAY → FWDLOOP; MOD → LFO with DEST LOOP ST.
  • OSC RAMP UP, TRIG RETRIG so each note restarts the scan
  • FREQ is in steps (10 = one bar); AMT sets how far it scans
Stutter FillsRET · LEN
  • RET 03 on a slice note repeats its start
  • LEN on the same step shortens each repeat for a tight glitch
