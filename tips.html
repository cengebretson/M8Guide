Macrosynth
808 KickSHAPE KICK
  • SHAPE → KICK: TIMBRE sets decay, COLOR sets tone
  • The note tunes the drum, so pick one in the song's key
  • Raise AMP with LIM set to SIN for extra weight
Snare & HatsSNARE · CYMBAL
  • SNARE: TIMBRE is tone, COLOR is snappy noise
  • CYMBAL: COLOR blends metal and noise, TIMBRE is brightness
  • Short AHD on volume for closed hats; KIL 02 cuts tighter
Plucked LeadSHAPE PLUCKED
  • TIMBRE is damping (length), COLOR is pluck position
  • Very low notes turn it into knocks and wood percussion
  • Add a DEL send and PSL slides for a guitar-like line
Chords on One TrackWAV PARAPHONIC
  • Four voices: COLOR picks the chord, TIMBRE morphs the wave
  • COL in the phrase changes the chord per step
  • COLOR 00 stacks unison voices for a thick detuned lead
FM Synth
Punchy FM KickDRUM ENV
  • One SIN carrier at RATIO 1.00, other operators at LEV 00
  • MOD1 → DRUM ENV with a high PEAK and short BODY
  • In the carrier's MOD slot, route MOD1 to PIT
  • MOD2 → AHD on volume; DEC sets the kick's length
Growling BassRATIO · LEV/FB
  • Carrier RATIO 1.00; modulator 1.00 or 2.00 (0.50 for a sub)
  • Modulator LEV sets brightness, FB adds grit
  • Short AHD on the modulator's LEV slot for a plucky attack
Hypersynth
Lush PadSWARM · WIDTH
  • CHORD: pick a bank and set its intervals (e.g. 0, 4, 7)
  • SWARM detunes the saws; WIDTH toward FF spreads them
  • ADSR on volume, slow ATK and long REL; end notes with OFF
Bass + Chord StabSUBOSC · SHIFT
  • SUBOSC below 80 is two octaves down, above 80 is one
  • Low CUTOFF and a short AHD on it for a stab
  • An LFO on SHIFT fades between intervals 1–3 and 4–6
Sampler
Chop a BreakSLICE
  • Sample editor: PROCESS → SLICE:AUTO (transients) or SLICE:16
  • SAVE, then set the instrument's SLICE to 01 FILE
  • Notes from C-1 up play slices in order; rearrange freely
Lazy ChopPLAY + EDIT
  • In the editor, highlight SLICE MARKER and play the sample
  • Tap PLAY + EDIT on each hit to drop a marker there
  • SAVE, set SLICE to 01 FILE, and play the slices from C-1
Loops in TempoREPITCH/BPM
  • PLAY → REPITCH/BPM, then set STEPS/BPM to the loop's length
  • The loop follows the song tempo (pitch moves with it)
  • OSC play modes ignore START, for sustained tones
Resample & MangleEDIT ×2
  • Song view: SHIFT + OPTION to select, then double-tap EDIT
  • QUICK RENDER makes a new sampler instrument
  • REVERSE, SQUISH(OTT) or DOWNSAMPLE it in the editor
Rhythm & Groove
Swing Only the HatsGRV
  • Groove view (SHIFT + UP from a phrase): make groove 01 07 05
  • Put GRV 01 on the hat track; others stay on groove 00
  • Subtler swing: raise the groove's PPQN to 48–192
Ghost Notes & FillsCHA · NTH · SED
  • CHA 8F plays the note about half the time (CHA 1F ≈ 10%)
  • NTH skips hits by loop count; read its on-screen help
  • SED at a section start makes the chances repeat each pass
Rolls & RatchetsRET
  • RET 03 retriggers every 3 ticks (32nds); RET 02 is faster
  • First digit ramps volume: 1–7 fades, 9–F swells
  • RET 30 plays a single repeat after 3 ticks (a flam)
Human FeelDEL · MTT · RND
  • DEL 03 pushes a row half a step late (6 ticks = 1 step)
  • MTT nudges by 1/8 tick; 80–FF is early (not on row 0)
  • VOL, then RND with a small range varies each hit

Tables
Looping ArpN · HOP 00
  • N column rows 0–3: 00, 04, 07, 0C (a major arpeggio)
  • HOP 00 on row 4 loops it; TABLE TIC sets the speed
  • Plucky sounds: RET 10 on the rows so each note re-strikes
Change Each HitTIC 00
  • TABLE TIC 00 moves the table one row per note
  • Put different CUT or PAN values down the rows
  • HOP 00 after the last used row cycles the pattern
Drum Kit on One TrackTIC FE · INS
  • TIC FE: the note picks the row (C is row 0, C# row 1, …)
  • INS on each row selects the kick, snare, or hat instrument
  • Program the whole beat by note name on a single track
Trance GateV COLUMN
  • Table V column: alternate loud and silent rows (FF, 00, …)
  • HOP 00 at the end loops it; TABLE TIC sets the gate rate
  • Works on any held pad or chord
Mix & FX
Sidechain PumpTRIG ENV
  • On the pad or bass: a MOD slot → TRIG ENV, DEST volume
  • SRC 80–87 picks the kick's track (80 is track 1)
  • Negative AMT ducks on each kick; DEC sets the recovery
Dub ThrowSDL
  • Keep the instrument's DEL send low for the groove
  • SDL FF on one hit, then SDL 00 on the next step
  • Long delay feedback lets the throw trail off
Build-Up SweepDJC · REP
  • DJC to start the DJ filter, then REP ramps it each tick
  • RTO sets where the ramp stops; DJR adds resonance
Carve SpaceEQ
  • Instrument EQ: pick a slot, then EDIT opens the EQ editor
  • Cut lows from pads and hats so the kick and bass stay clear
Grit & WarmthAMP · LIM
  • Raise AMP: LIM SIN is soft, FOLD and WRAP are aggressive
  • POST:AD soft-clips after the filter for analog drive
