Song & Arrangement
Tracks That DriftCHAIN LENGTH
  • Each track loops its own chains at the first empty “--”
  • Chains of different lengths drift apart for polymeters
  • Keep a silent track aligned with a chain of silent phrases
Remix a PatternRMX
  • Put RMX XY on a control track to the right of your pattern
  • X picks affected tracks; Y picks the phrase row to jump to
  • Try rows 0, 4, 8, C for rearranged beats; use FX help for X
One Phrase, Many KeysCHAIN TSP
  • The chain's TSP column transposes each phrase in semitones
  • Reuse one bassline for a whole progression
  • Turn TRANSP. off on drum instruments so they stay put
Layer InstrumentsNXT
  • NXT XX plays instrument XX on the track to the right
  • It shares the note and velocity; reserve that track for it
  • Layer a bass with a click or bright attack; not on track 8
Custom & Microtonal ScalesSCALE VIEW
  • Load one of 92 factory scales from /Scales/Factory
  • Toggle notes with EN; detune any note ±24 semitones
  • SCA assigns a scale and key per track, SCG for all
Live Performance
Live Mode JamsSHIFT + LEFT
  • From Song view, SHIFT + LEFT enters live mode
  • PLAY cues a chain per track; SHIFT + PLAY stops a track
  • LIVE QUANTIZE in Project view sets when cues start
Mute & Solo MovesOPT + SHIFT
  • OPTION + SHIFT mutes, OPTION + PLAY solos
  • Release OPTION first to latch the mute or solo
  • OPTION + LEFT/RIGHT solos every track on that side
  • OPTION + SHIFT + PLAY clears them all for the drop
Tweak, Then UndoSNAPSHOT
  • Mixer view: SHIFT + OPTION stores a song snapshot
  • Mangle freely, then SHIFT + EDIT recalls it
Drop Changes on the BeatPROJECT
  • TRANSPOSE, GROOVE and SCALE apply when EDIT is released
  • Dial in the value, then release EDIT on the downbeat
  • Tap EDIT in rhythm on TEMPO to set the tempo by tapping
Rhythm & Groove
Swing Only the HatsGRV
  • Groove 01: alternate rows 07, 05 (SHIFT + UP from Phrase)
  • Put GRV 01 on the hat track; others stay on groove 00
  • Higher PPQN gives finer timing; adjust tick counts to match
Ghost Notes & FillsCHA · NTH · SED
  • CHA 8F plays the note about half the time (CHA 1F ≈ 10%)
  • NTH skips hits by loop count; read its on-screen help
  • SED at a section start makes the chances repeat each pass
Rolls & RatchetsRET
  • RET 03 retriggers every 3 ticks (32nds); RET 02 is faster
  • First digit ramps volume: 1–7 fades, 9–F swells
  • RET 30 plays a single repeat after 3 ticks (a flam)
Human FeelDEL · MTT · RND
  • DEL 03 delays 3 ticks: half a step in the default groove
  • MTT nudges by 1/8 tick; 80–FF is early (not on row 0)
  • VOL, then RND with a small range varies each hit
Mix & Master
Sidechain PumpTRIG ENV
  • On the pad or bass: a MOD slot → TRIG ENV, DEST volume
  • SRC 80–87 picks the kick's track (80 is track 1)
  • Negative AMT ducks on each kick; DEC sets the recovery
Dub ThrowSDL
  • SDL FF on one hit, then SDL 00 on the next step
  • Effect Settings (Mixer, SHIFT + DOWN): TIME 40 = 4 beats
  • High FEEDBACK lets the throw trail off
Build-Up SweepDJC · DJT
  • DJ filter: 80 is off, lower is low-pass, higher is high-pass
  • DJC then REP ramps it each step; RTO sets where it stops
  • TYPE switches to band-stop modes; DJR adds resonance
Freeze a Reverb TailXRZ
  • Send a chord to reverb; XRZ 01 on a later row freezes its tail
  • Hold it under a breakdown; XRZ 00 releases the freeze
Glue the MixOTT · LIM
  • Mixer OTT from 00 to 80 blends in parallel multiband squash
  • LIM above 00 engages the master limiter; watch the scope
  • SOFT CLIP in the scope view (EDIT on LIM) tames harsh peaks
Drums Animate a PadTRIG ENV
  • Pad: TRIG ENV → CUTOFF; SRC 80–87 picks the drum track
  • Low cutoff, positive AMT, short DEC: each hit opens the pad
Tables
Looping ArpN · HOP 00
  • N column rows 0–3: 00, 04, 07, 0C (a major arpeggio)
  • HOP 00 on row 4 loops it; TABLE TIC sets the speed
  • Plucky sounds: RET 10 on the rows so each note re-strikes
Change Each HitTIC 00
  • TABLE TIC 00 moves the table one row per note
  • Put different CUT or PAN values down the rows
  • HOP 00 after the last used row cycles the pattern
Drum Kit on One TrackTIC FE · INS
  • TIC FE: the note picks the row (C is row 0, C# row 1, …)
  • INS on each row selects the kick, snare, or hat instrument
  • HOP 00 on row 0C repeats the 12-note kit across octaves
Trance GateV COLUMN
  • Table V column: alternate loud and silent rows (FF, 00, …)
  • HOP 00 at the end loops it; TABLE TIC sets the gate rate
Custom LFO ShapesCUT · HOP
  • Relative FX add offsets, not targets: 01 adds 1, FF subtracts 1
  • For a CUT rise and fall, balance positive and negative offsets
  • HOP 00 loops it; tables also loop at the bottom by default
Columns at Different SpeedsTIC IN TABLE
  • TIC inside a table sets the rate for that FX column only
  • Loop columns at different lengths for shifting motion
A Second Table per NoteTBX
  • TBX XX in a phrase runs table XX alongside the instrument's table
  • TIC on the same row sets its speed; THO there hops into it
  • TBX 00 stops it
Octave & Velocity MapsTIC FC · FD
  • TIC FC: the octave picks the row; TIC FD: the velocity does
  • INS per row switches sounds by octave or velocity
Random Notes & AccentsCHA · RNL
  • CHA in a table sets odds for everything left of it (00–FF)
  • RNL in the first FX column randomizes note and velocity
Repeat, Then Move OnHOP 30
  • HOP XY in a table jumps to row Y, X times, then carries on
  • Rows 0–3 an arp; HOP 30 on row 4 jumps back three times
  • Rows 5 and up can fade it out or switch to a new pattern
